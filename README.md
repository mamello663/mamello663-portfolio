# mamello663-portfolio

This repository contains a single-page portfolio website (HTML/CSS/JS) for Mamello.

How to publish with GitHub Pages:
1. Go to the repository Settings > Pages.
2. Under "Build and deployment", choose "Deploy from a branch" and select the `main` branch, folder `/ (root)`.
3. Save — GitHub will publish the site at https://mamello663.github.io/mamello663-portfolio/

Edit the content in index.html, styles.css, and script.js to personalize the site.
